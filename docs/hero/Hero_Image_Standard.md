# GogoPar Hero Image Standard v1.0

## 목적

GogoPar Hero 이미지는 단순한 배경이 아니라 **실제 골프장의 아이덴티티를
재현한 Hero Digital Twin**을 구축하는 것을 목표로 한다.

------------------------------------------------------------------------

# Workflow

``` text
골프장명 입력
    │
    ▼
① 골프장 리서치
    │
    ▼
② 리서치 리포트 생성
    │
    ▼
③ Gemini Hero Prompt 생성
    │
    ▼
④ Hero 이미지 생성
    │
    ▼
⑤ 품질검사
    │
    ▼
⑥ DB 등록
    │
    ▼
⑦ Hero 적용
```

------------------------------------------------------------------------

# 리서치 규칙

Gemini는 이미지를 생성하기 전에 반드시 웹 리서치를 수행한다.

## 조사 대상

-   공식 홈페이지
-   Google Search
-   Google Maps
-   Google Earth
-   위성사진
-   드론 사진 및 영상
-   골프장 리뷰
-   Naver
-   Kakao Map
-   YouTube
-   Instagram
-   골프 블로그

최소 **20\~100장의 실제 사진**을 분석한다.

------------------------------------------------------------------------

# 리서치 리포트

이미지 생성 전에 아래 내용을 먼저 작성한다.

-   조사한 사진 수
-   사용한 출처
-   대표홀(Signature Hole)
-   대표 뷰포인트
-   클럽하우스 특징
-   산세
-   수목
-   수계
-   페어웨이 특성
-   계절감
-   촬영 시점 선정 이유

------------------------------------------------------------------------

# Hero 이미지 생성 규칙

-   실제 골프장의 지형을 유지
-   실제 클럽하우스 유지
-   실제 산세 유지
-   실제 수목 유지
-   실제 대표홀 유지
-   새로운 풍경 창작 금지

## 스타일

-   Photorealistic
-   Luxury Golf Resort
-   Premium Digital Matte Painting
-   AAA Environment Quality

# 이미지 규격

  항목     값
  -------- -------------
  Master   3840 × 2160
  비율     16:9
  포맷     PNG
  배포     WebP

좌측 35%는 Hero UI Safe Area로 유지한다.

# 품질 체크리스트

  항목                 점수
  -------------------- ------
  실제 골프장 재현성   40
  대표홀 표현          20
  클럽하우스           10

``` text
    hero_prompt.md

```

# 장기 운영 계획

계절 및 날씨별 Hero 라이브러리를 구축한다.

``` text
Spring/
Summer/
Autumn/
Winter/

└── Sunny
└── Cloudy
└── Rain
└── Snow
```

실시간 날씨 API와 연동하여 Hero 이미지를 자동 변경한다.
