# COMPONENT_GUIDE

## Base UI Components

- GPButton
- GPCard
- GPSection
- GPBadge
- GPChip
- GPAvatar
- GPText

## Home Components

- HomeHeroSection
- QuickMenuSection
- TodayRoundCard
- AICaddieCard
- RecentStatsSection
- CommunityPreviewSection

## Component Rule

- Screen은 화면 조립과 데이터 연결을 담당합니다.
- Section은 하나의 정보 묶음을 담당합니다.
- Card는 하나의 사용자 행동 또는 정보 단위를 담당합니다.
- Widget은 Card 내부의 작은 표시 요소로만 사용합니다.
- 새 컴포넌트는 Props 기반으로 작성하고 API 호출을 직접 하지 않습니다.
