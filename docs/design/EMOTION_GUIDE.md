# GogoPar Emotion Guide

## 1. 핵심 철학

**골프는 기록이 아니라 추억입니다.**

GogoPar의 모든 기능은 사용자가 골프를 더 기대하고, 더 즐기고, 더 오래 기억하도록 도와야 한다.

---

## 2. 기능별 목표 감정

| 상황 | 사용자가 느껴야 하는 감정 |
|---|---|
| 앱 첫 실행 | 설렘 |
| 예정 라운드 있음 | 기대감 |
| 라운드 당일 | 응원받는 느낌 |
| 라운드 없음 | 골프 가고 싶다 |
| 베스트 스코어 | 자랑하고 싶다 |
| 기록 입력 완료 | 뿌듯함 |
| 조편성 완료 | 준비가 끝났다 |
| Lotto | 재미 |
| 캐디북 | 든든함 |
| 비 오는 날 | 아쉬움 + 대안 |
| 오랜만의 라운드 | 반가움 |

---

## 3. Home의 감정

Home은 메뉴판이 아니라 클럽하우스다.

사용자는 앱을 열었을 때 다음을 느껴야 한다.

```text
오늘 골프가 기대된다.
내 라운드를 기억해준다.
준비가 잘 되어 있다.
혼자가 아니라 GOGO가 함께한다.
```

---

## 4. 메시지 원칙

문장은 짧고 따뜻하게 쓴다.

좋은 메시지:

```text
오늘도 버디 가볼까요?
라운드 준비는 완벽해요.
이번 주말 한 게임 어떠세요?
지난번 보문CC 기억나시나요?
```

피해야 할 메시지:

```text
예정된 라운드가 없습니다.
데이터를 불러오는 중입니다.
API 호출에 실패했습니다.
```

---

## 5. 감정 우선순위

상태가 겹칠 경우 아래 감정을 우선한다.

```text
1. 라운드 당일: 응원
2. 베스트 기록: 축하
3. 예정 라운드: 기대
4. 비 오는 날: 위로
5. 라운드 없음: 제안
```
