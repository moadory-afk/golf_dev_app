# GogoPar Home V2 설계서

## 목적

Home V2는 단순 메뉴가 아닌 골프를 시작하는 첫 화면(Club House)이다.

## 화면 구성

1.  Top Bar
2.  Hero Section
3.  Gogo Caddie Card
4.  Stats Cards
5.  Upcoming Round Ticket
6.  Quick Actions
7.  Bottom Navigation

## Hero

### 예정 라운드 있음

-   골프장 Hero 이미지
-   인사말
-   날씨 / 온도
-   D-Day
-   Tee Time
-   코스명

### 예정 라운드 없음

-   추천 골프장 Hero
-   라운드 등록 CTA
-   Gogo 메시지

## Gogo Caddie

-   캐릭터
-   오늘의 한마디
-   액션 버튼

## 통계 카드

-   핸디캡
-   평균 스코어
-   최근 라운드
-   베스트 스코어

## 라운드 티켓

-   날짜
